# 额度悬浮窗 v2.1 使用说明

桌面常驻悬浮窗，一眼看清**智谱 GLM Coding Plan**和**火山引擎 Agent Plan**的额度用量。

## 一、快速开始（只需三步）

1. 双击 `额度悬浮窗.exe`（无需安装 Python）
2. 首次运行会自动弹出**设置窗口**，填入密钥后点「保存并应用」
3. 悬浮窗出现，完成

> 密钥只保存在本目录的 `config.json` 里，软件不会上传到任何服务器。

## 二、日常使用

| 操作 | 方式 |
|---|---|
| 移动位置 | 按住鼠标左键拖动，位置自动记忆 |
| **贴边收起** | 拖到屏幕边缘松手 → 自动滑入收起，边缘留一个进度小条 |
| **从收起中唤出** | 鼠标移到边缘的进度小条上 → 自动弹出；移开后自动收回 |
| **切换形态** | 右键 → 显示形态 → 卡片式 / 圆环式 |
| **切换配色** | 右键 → 配色主题 → 自动（跟随背景）/ 深色 / 浅色 |
| 打开菜单 | 鼠标右键点悬浮窗（收起状态下小条也可以右键） |
| 立即刷新 | 右键 → 立即刷新 |
| 修改设置 | 右键 → 设置… |
| 开机自启 | 右键 → 开机自启 → 设置 |
| 退出 | 右键 → 退出 |
| 重复打开 | 已在运行时会提示，不会出现两个浮窗 |

## 三、两种显示形态

### 卡片式（默认）

和 v2.0 一样的双卡片布局，每个供应商一张卡，带标题、档位标签和横向进度条。

### 圆环式（v2.1 新增，更小）

每个供应商一组双圆环仪表盘，体积只有卡片的一半左右：

- **外环**：5 小时窗口进度（火山是"今日"），圆头端帽
- **内环**：本周进度
- **环中心**：大字显示最重要的 5 小时百分比（颜色随阈值变化），下方一行小字是供应商名
- **鼠标悬停**：浮窗旁弹出详情小卡（各窗口百分比 + 更新时间）

## 四、贴边自动收起（v2.1 新增）

把悬浮窗拖到屏幕任意一条边（左右上下都行）附近松手：

1. 悬浮窗**自动滑入屏幕边缘**收起，完全不挡内容
2. 边缘留一条**极窄的进度小条**：每个供应商一组微型进度条
   （左右贴边时是两根竖条：一根 5 小时、一根本周，像液体液位一样从底部涨起来；上下贴边时是两根横条）
3. 颜色规则和主界面一致：绿=正常、黄=偏高、红=临界 —— **不用扒开也能一眼看到用量**
4. 鼠标移到小条上 → 自动滑出**完整详情面板**（见下节）；鼠标移开 → 自动收回
5. 从收起状态按住拖动 → 直接拽出来放到别处

不想用这个功能：右键 → 取消勾选「贴边自动收起」。

### 详情面板（鼠标移上小条后展开）

不再受紧凑卡片的大小限制，完整展示所有额度信息：

- **每个供应商**：名称、套餐等级徽章
- **每个额度窗口**：用量百分比（大字）+ 进度条 + **重置倒计时和绝对时间**
  （如「35 小时 14 分后重置 · 9月6日（周日）10:08」）
- **智谱 MCP 联网工具**：月度用量、重置日期、分模型明细（search-prime / web-reader / zread）
- **火山窗口**：已用 / 总量数值（如「已用 1200 / 5.0w」）
- **页脚**：更新时间、自动刷新间隔

数据超过 2 分钟没刷新时展开会自动拉取最新额度；面板停留期间每 30 秒自动刷新倒计时。
把面板**拖离边缘**即恢复为普通紧凑卡片。

> 收起状态、贴哪条边都会记忆，重启程序自动恢复。

## 五、设置项说明（右键 → 设置…）

### 供应商页

| 设置 | 说明 |
|---|---|
| 启用 智谱 Coding Plan | 不需要就取消勾选，卡片立即隐藏 |
| API Key | 智谱开放平台 → API Keys 页面获取 |
| 接口地址 | 默认 `open.bigmodel.cn`；国际版（z.ai）填 `api.z.ai` |
| 启用 火山引擎 Agent Plan | 同上，只用智谱就取消勾选 |
| AccessKey ID / SecretAccessKey | 火山引擎控制台 → 右上角头像 → **API 访问密钥**（AKLT 开头）。注意：**不是**方舟里的模型 API Key |
| 地域 | 一般 `cn-beijing` |

> 只用智谱一家？把火山的「启用」取消勾选即可，浮窗只显示智谱，更省地方。

### 显示页

| 设置 | 说明 |
|---|---|
| 配色主题 | 深色 / 浅色 / 自动（跟随背景）——自动模式会感应窗口背后的背景明暗切换深浅色 |
| 显示形态 | 卡片式 / 圆环式 |
| 贴边收起 | 开关"拖到边缘自动收起"功能 |
| 界面缩放 | 75%（紧凑）～130%（大），觉得浮窗太大/太小就调这里，保存后立即生效 |
| 窗口透明度 | 60% ～ 100% |
| 自动刷新间隔 | 1 ～ 120 分钟 |
| 黄色/红色阈值 | 用量超过黄档变黄、超过红档变红 |

### 颜色规则

- 绿色：正常（低于黄色阈值）
- 黄色：偏高（≥ 黄色阈值，默认 80%）
- 红色：临界（≥ 红色阈值，默认 95%）

## 六、显示内容

| 供应商 | 窗口 | 含义 |
|---|---|---|
| 智谱 Coding Plan | 5小时 | 当前 5 小时滚动窗口已用百分比 |
| | 本周 | 本周额度已用百分比 |
| 火山 Agent Plan | 5小时/今日/本周/本月 | 各滚动窗口配额已用百分比（套餐档位显示在标题旁） |

## 七、常见问题

| 现象 | 原因与解决 |
|---|---|
| 白色背景下看不清 | 配色主题设为「浅色」，或用「自动（跟随背景）」；透明度调太低也会冲淡对比，建议 80% 以上 |
| 提示「API Key 无效或已过期」 | Key 复制不完整或已失效，重新从智谱控制台复制 |
| 提示「InvalidAccessKey」 | 填的是方舟模型 Key；要用控制台头像 → API 访问密钥 里 AKLT 开头那对 |
| 提示「SignatureDoesNotMatch」 | SecretAccessKey 复制不完整，重新完整复制 |
| 双击没反应 | 看看是否已有悬浮窗在运行（单实例保护）；或查看本目录 `error.log` |
| 收起后找不到悬浮窗 | 看屏幕四条边上的窄进度条，鼠标移上去就会弹出；或重启程序 |
| Windows 弹防火墙提示 | 允许即可（需要联网查额度） |
| 公司网络一直更新失败 | 需要代理的网络暂不支持，可换家庭网络 |
| 浮窗跑到屏幕外 | 重启程序会自动复位到默认位置 |

## 八、v2.1 更新内容

- **圆环形态**：双环进度显示（外环 5 小时 / 内环本周），体积更小，中心大字直接显示百分比，悬停弹出详情
- **贴边自动收起**：拖到屏幕边缘自动滑入收起，边缘留微型进度条持续显示用量，鼠标移上自动弹出、移开自动收回
- **详情面板**：贴边悬停展开后是完整额度面板——各窗口用量、重置倒计时与绝对时间、MCP 分模型明细、套餐等级、更新时间
- **配色主题**：深色 / 浅色 / 自动跟随背景明暗（白色桌面自动换浅色配色，不再看不清）
- **形态/主题/贴边即时切换**：右键菜单和设置窗口都能改，立即生效并记忆

## v2.0 更新内容

- **修复高分屏文字模糊**：正确适配系统缩放（125%/150%/200% 都清晰锐利）
- **修复密钥丢失 bug**：旧版在程序运行期间手动编辑 config.json 填的密钥会被覆盖丢失，导致一直显示"未配置"；现在全部改为增量保存
- **新增设置窗口**：所有配置图形化编辑，不再需要记事本改 JSON
- **界面缩放可调**：75%（紧凑）～130%（大），浮窗太大太小随时调
- **供应商可开关**：只想看智谱就关掉火山卡片
- **单实例保护**：重复双击不会出现多个浮窗
- **窗口位置防丢失**：改分辨率/换显示器后位置自动复位
- **崩溃日志**：出问题看同目录 `error.log`
