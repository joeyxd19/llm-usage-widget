# 版本日志

每个版本一个子文件夹，内含当版的完整源码、EXE 和使用说明。
想回到某一版：直接运行对应文件夹里的 EXE 即可（或把 `usage_widget.pyw`
拷回 `智谱用量监控桌面应用\usage-widget\` 后重新打包）。

> 注意：旧版 EXE 和新版共用同一份 `额度悬浮窗\config.json` 配置，
> 回退版本后配置里的新字段会被忽略，不影响使用。

## v2.3.1 短把手（最新）

- 贴边收起的进度小条改为固定短条（约 120×缩放系数像素），
  不再随详情面板高度变长

## v2.3 单一详情页

- 移除圆环式、卡片式两种形态：不贴边时主窗口直接显示完整详情面板
- 右键菜单与设置窗口移除「显示形态」选项
- 修正：主窗口按详情面板尺寸定位与边界钳制

## v2.2 详情面板

- 贴边悬停展开改为完整详情面板：各窗口额度百分比、重置倒计时与绝对时间、
  MCP 分模型用量、套餐等级、更新时间
- 数据超过 2 分钟未刷新时展开自动拉取；面板停留期间每 30 秒刷新倒计时
- 验证结论：5 小时/本周窗口映射正确（5 小时窗口每 5 小时整清零一次）

## v2.1 圆环 + 贴边 + 主题

- 圆环形态（本版后被移除）
- 贴边自动收起：边缘微型进度条，鼠标移上展开
- 配色主题：深色 / 浅色 / 自动跟随背景明暗
- 拖动时临时恢复不透明的逻辑移除（保留事件节流防抖）

## v2.0 设置窗口 + 高分屏修复

- DPI 感知渲染，修复高分屏文字模糊
- 图形化设置窗口：密钥、缩放、透明度、刷新间隔、阈值、供应商开关
- 配置增量保存，修复 API Key 被覆盖丢失
- 网络策略：优先直连，失败回退代理
- PyInstaller 打包为独立 EXE

## v1.x 初始版本

- 智谱 + 火山双供应商额度悬浮窗，命令行配置
