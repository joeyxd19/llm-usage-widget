# 版本日志

每个版本一个子文件夹，内含当版的完整源码、EXE 和使用说明。
想回到某一版：直接运行对应文件夹里的 EXE 即可（或把 `usage_widget.pyw`
拷回 `智谱用量监控桌面应用\usage-widget\` 后重新打包）。

> 注意：旧版 EXE 和新版共用同一份 `额度悬浮窗\config.json` 配置，
> 回退版本后配置里的新字段会被忽略，不影响使用。

## v2.3.3 火山窗口修正 + 移开立即收回（最新）

- 修正火山额度窗口：官方 Agent Plan 只有 5 小时 / 周 / 月 三档限额，
  去掉 API 里固定 10000 的「今日」占位窗口（比周限额还大，不构成约束；
  此前详情面板按前 3 个展示，「今日」还把「本月」挤出了显示范围）
- 贴边展开后鼠标移开立即收回，去掉 800ms 延时

## v2.3.2 网络加固 + 密钥容错

- 修复火山引擎一直显示「网络错误」的主因：AK 栏误粘成
  「AK\nSecret Access Key:xxx」整段，请求头带换行发不出去；现在自动拆分
- 密钥统一 strip 清洗；「请求格式错误 / AK 无权限 / 真网络错误」分开提示
  （AccessDenied 会直接提示去火山控制台给子用户加 ArkFullAccess 授权）
- 网络加固：超时 15s→20s；直连+系统代理两路全败时停 2 秒重试一轮，
  对抗本机代理客户端造成的 DNS/路由间歇抖动（实测偶发解析失败、连接卡 15~35s）

## v2.3.1 短把手

- 贴边收起的进度小条改为固定短条（约 70×缩放系数像素，200% 缩放下约 140px），
  不再随详情面板高度变长

## v2.3 单一详情页

- 移除圆环式、卡片式两种形态：不贴边时主窗口直接显示完整详情面板
- 右键菜单与设置窗口移除「显示形态」选项
- 修正：主窗口按详情面板尺寸定位与边界钳制

## v2.2 详情面板

- 贴边悬停展开改为完整详情面板：各窗口额度百分比、重置倒计时与绝对时间、
  MCP 分模型用量、套餐等级、更新时间
- 数据超过 2 分钟未刷新时展开自动拉取；面板停留期间每 30 秒刷新倒计时
- 验证结论：5 小时/本周窗口映射正确（5 小时窗口每 5 小时整清零一次）

## v2.1 圆环 + 贴边 + 主题

- 拖动时临时恢复不透明的逻辑移除（保留事件节流防抖）
