# 版本日志

自 v2.4.0 起仓库采用 src / docs / scripts / release 分层结构；
更早版本的源码与 EXE 留档可通过 GitHub 提交历史回溯。

> 注意：config.json 含密钥不入库，始终生成在 EXE / 源码同目录；
> 升级或回退版本时配置互相兼容，新字段会被旧版忽略。

## v2.4.3 智谱近 30 天 token 用量（最新）

- 详情面板智谱区新增「近 30 天用量」一行：显示过去 30 天累计消耗的
  token 总数与调用次数（如 `1.83亿 tokens · 1.2w 次`），位于「本周额度」
  与「MCP 联网工具」之间
- 数据来自智谱 `/api/monitor/usage/model-usage` 接口（与额度接口同族同认证、
  无公开文档）：每次刷新附带一次查询，startTime 取当前时间前推 30 天，
  读取返回中的 `totalUsage.totalTokensUsage / totalModelCallCount`
- 设置窗口「供应商」页新增开关「显示近 30 天 token 用量」（默认开启，
  写入 zhipu.show_30d）；接口请求失败时静默降级隐藏该行，不影响原有额度显示
- 顺带修正 APP_VERSION 滞后：v2.4.2 发布时源码版本号停留在 2.4.1 未同步

## v2.4.2 贴边长条默认长度 150px

- 贴边收起小条的默认长度由 70px 调整为 150px，开箱即用无需再调
- DEFAULT_CONFIG 补充 dock_len 字段，旧配置不受影响（升级后沿用原值，新装机默认 150）

## v2.4.1 修复开机自启

- 修复「设置开机自启」生成的 usage_widget.vbs 语法错误（800A0401 语法未结束）：
  源码模式下 Run 命令里解释器与脚本两个带引号路径直接相邻，属非法 VBScript，
  现改为整体包一对引号、内部路径引号成对转义的标准写法
- 源码模式自启若检测到由 python.exe 启动，自动改用同目录 pythonw.exe，
  避免开机时闪现控制台窗口
- 打包版自启直接启动 EXE 本体，不再依赖本机 Python 环境

## v2.4.0 目录重构 + EXE 一键启动

- 仓库结构重构为 `src/`（源码）、`docs/`（文档）、`scripts/`（启动脚本）、
  `release/`（EXE 产物）四层，移除仓库内冗余的源码 zip 快照与 .uploads 杂项，
  根目录一眼可读
- 新增 PyInstaller 一键打包：release\额度悬浮窗.exe 双击即用，无需安装 Python；
  config.json 仍生成在 EXE 同目录，升级不丢配置
- 启动.vbs 改为优先启动 release 下的 EXE，找不到 EXE 时回退用官方 Python
  运行 src\usage_widget.pyw
- 文档集中到 docs\（使用说明.md + 版本日志.md），README 同步更新目录说明

## v2.3.7 长条长度设置

- 新增「长条长度」设置：显示页可调贴边收起小条的长度（40～240 逻辑像素，
  默认 70，随界面缩放），保存后立即生效——收起状态下改动即时按新长度重画
  并夹回屏幕内
- 把手长度改读配置 dock_len，展开/收回/入坞定位沿用同一尺寸来源，不会错位

## v2.3.6 智谱窗口映射修正

- 修复智谱 5 小时/本周额度显示颠倒：接口返回两个 TOKENS_LIMIT 窗口，此前按
  nextResetTime 重置时间先后猜测归属——5 小时窗口尚未激活时该字段为空被排到
  最后，本周额度（如 45%）被错挂到「5 小时窗口」名下显示
- 改为按接口自带的 unit/number 字段显式识别（实测：unit=3 number=5 为
  5 小时窗口，unit=6 number=1 为本周窗口），不再依赖排序；字段缺失时保留
  旧的排序逻辑兜底
- 详情面板窗口名称与数值严格成对输出，固定 5 小时窗口在前

## v2.3.5 收回动画修正

- 修复收回动画斜向漂移：v2.3.4 居中展开后，收回时窗口从"面板顶"动画到
  "把手顶"，垂直方向带着 (面板高-把手长)/2 的位移一起走（200% 缩放下约
  380px），看起来是斜着坠出去的；改为只沿贴边方向直线滑出，滑到屏幕外
  再对齐把手坐标重绘，入坞（拖到边缘收起）同样处理
- 修复夹取漂移：展开位置被屏幕边缘夹取时，收回按夹取后的面板位置反推
  把手落点导致偏移；展开时记下把手原位，收回严格原位返回
- 顺带修正：入坞后写入配置的窗口坐标此前是屏幕外的动画终点值
  （贴边方向坐标会被强制校正所以未显现），现在保存真实把手位置

## v2.3.4 贴边居中展开 + 边缘误收回修复

- 贴边展开的详情面板改为以把手（进度小条）**中心对齐**弹出：
  左右贴边垂直居中、上下贴边水平居中，不再固定上边对齐；
  收回时把手回到原位，关掉贴边开关恢复窗口时也按把手中心定位
- 修复屏幕边缘误收回：面板边线与屏幕边缘重合时，鼠标顶到屏幕最边缘
  会被系统误报为「移开」导致面板缩回；现在按指针实际位置复核（含 2px 容差），
  并在展开期间每 300ms 兜底轮询，指针真离开才收回

## v2.3.3 火山窗口修正 + 移开立即收回

- 修正火山额度窗口：官方 Agent Plan 只有 5 小时 / 周 / 月 三档限额，
  去掉 API 里固定 10000 的「今日」占位窗口（比周限额还大，不构成约束；
  此前详情面板按前 3 个展示，「今日」还把「本月」挤出了显示范围）
- 贴边展开后鼠标移开立即收回，去掉 800ms 延时

## v2.3.2 网络加固 + 密钥容错

- 修复火山引擎一直显示「网络错误」的主因：AK 栏误粘成
  「AK\nSecret Access Key:xxx」整段，请求头带换行发不出去；现在自动拆分
- 密钥统一 strip 清洗；「请求格式错误 / AK 无权限 / 真网络错误」分开提示
  （AccessDenied 会直接提示去火山控制台给子用户加 ArkFullAccess 授权）
- 网络加固：超时 15s→20s；直连+系统代理两路全败时停 2 秒重试一轮，
  对抗本机代理客户端造成的 DNS/路由间歇抖动（实测偶发解析失败、连接卡 15~35s）
