# 版本日志

自 v2.4.0 起仓库采用 src / docs / scripts / release 分层结构；
更早版本的源码与 EXE 留档可通过 GitHub 提交历史回溯。

> 注意：config.json 含密钥不入库，始终生成在 EXE / 源码同目录；
> 升级或回退版本时配置互相兼容，新字段会被旧版忽略。

## v2.5.7 修复分段选择器文字不可见 + 文字随 DPI 缩放（最新）

- **分段选择器文字隐身**：CTkSegmentedButton 的 text_color 是全局生效的，
  此前把为蓝色选中底设计的深色文字（#0e1020）应用到了所有分段——
  未选中的深底格上"深字配深底"，"深色/浅色/75%/90%…"几乎看不见
  （看起来像文字被截掉）。现按分段逐格着色：选中格深字配蓝底，
  未选中格浅字配深底
- **文字随 DPI 缩放**：CTkFont 字号是绝对像素、不随 DPI 缩放，而控件
  高度会被 CTk 放大——高分屏（如 125%）上文字比设计小约 20%。
  现按窗口缩放系数同步放大字号，文字与控件比例恢复一致

## v2.5.6 设置窗口改为舒适默认高度

- v2.5.5 按内容实际高度开窗导致窗口过长（贴满 88% 屏高）；
  现改为约 600 逻辑像素的舒适默认高度（与常见软件设置窗口一致），
  内容超出时在窗口内滚动查看

## v2.5.5 设置窗口三连修：尺寸 / 字体 / 控件质感

- **窗口尺寸**：设置内容挂在滚动 Canvas 里，Canvas 的自然高度不包含内容，
  导致开窗高度按空 Canvas 计算、大部分元素被截到屏幕外。现改为按页面
  实际内容高度开窗（上限屏高 88%，超出窗口内滚动），打开即可看全
- **字体**：字体族此前优先 Segoe UI，中文字形被系统回退到宋体，
  小字号下发虚发毛。现改为 Microsoft YaHei UI 优先（中英文完整字形），
  CTk 版字号按像素定义，各 DPI 下观感一致
- **控件质感**：设置窗口引入 CustomTkinter 重写——真圆角抗锯齿按钮、
  原生观感的开关 / 分段选择器 / 复选框 / 可滚动内容区，配色沿用
  v2.5.3 的深浅两套皮肤；未安装 customtkinter 时自动回退到修好的经典版
- 修复 CTkToplevel 外观模式切换时序问题（浅色模式下窗口卡在隐藏状态）
- 打包：Actions 与本地打包命令加入 customtkinter；EXE 仍为单文件，
  体积约增大 15 MB
- 说明：单文件并非 UI 效果的限制，此前问题均为实现层面 bug 与
  经典 Tk 控件的表现力所致

## v2.5.0 系统通知预警 + 烧速预测

- **系统通知预警**：用量跨过黄/红阈值、按烧速预测撑不到重置、
  5 小时窗口临近重置（≤20 分钟且用量偏高）时弹 Windows 系统通知；
  每个窗口期每类提醒只触发一次，不打扰；设置 → 显示页可整体开关
- **烧速预测**：每次刷新把各窗口用量百分比存入本地 `history.jsonl`
  （保留 14 天，自动清理），对 5 小时 / 本周窗口做最小二乘斜率外推；
  撑不到重置时面板显示红色"烧速 X%/时 · 预计 Y 后用尽（重置还需 Z）"，
  按当前烧法到重置会破黄线时显示黄色预估，安全时保持安静
- 预测需要 ≥4 个采样点且跨度 ≥20 分钟（约启用 20 分钟后可用）；
  窗口重置（百分比大幅回落）自动截断，不会用上一窗口的数据污染预测
- 通知实现为 Shell_NotifyIcon 气泡（Win10+ 自动呈现为 Toast），
  纯标准库 ctypes，托盘图标仅在通知期间临时注册、30 秒自动移除
- 兼容修复：ctypes.wintypes 无 GUID（Python 3.13）时内联定义

## v2.4.9 修复：右键菜单关闭后悬浮窗不收回

- 修复：在窗口上右键弹出菜单后，点击别处关闭菜单，悬浮窗不会自动收回的问题
- 原因是右键菜单打开时设置的 `_suppress_collapse` 标志在菜单关闭后未重置，
  导致收回逻辑一直被跳过；现在菜单关闭后立即复位标志，并检查指针位置，
  若已离开窗口则正常启动收回计时

## v2.4.8 修复：长条长度设置被重置回 150

- 修复：设置里的「长条长度」保存后，每次刷新（默认 5 分钟）或重启
  都被重置回默认 150px 的问题
- 原因是 load_config 的配置合并白名单漏了 dock_len 字段，
  磁盘上存了值但读不回来，刷新时把内存值覆盖为默认；
  贴边收起后把手一直可见，最容易察觉
- 现在设置一次长期生效，重启、刷新、切换贴边方向都不会再丢

## v2.4.7 修复：点击展开面板后不再自动收回

- 修复：悬停展开后单击面板（未拖动），鼠标移开时面板不再收回、
  且永久失去贴边自动收放的问题
  原因是按下左键即把面板转成自由窗口，Leave 事件因状态不符被跳过；
  现在纯点击保持贴边展开态，只有真正拖动才解除贴边
- 顺带加固：拖动过程中忽略 Leave 事件（隐式抓取可能触发误收回）
