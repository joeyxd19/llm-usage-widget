# 额度悬浮窗 使用说明

桌面常驻悬浮窗，一眼看清**智谱 GLM Coding Plan**和**火山引擎 Agent Plan**的额度用量。

## 一、快速开始（只需三步）

1. 到 [Releases 发布页](https://github.com/joeyxd19/llm-usage-widget/releases) 下载最新 `llm-usage-widget_vX.X.X.exe`，双击运行（无需安装 Python）
2. 首次运行会自动弹出**设置窗口**，填入密钥后点「保存并应用」
3. 悬浮窗出现，完成

> 密钥只保存在本目录的 `config.json` 里，软件不会上传到任何服务器。

## 二、日常使用

| 操作 | 方式 |
|---|---|
| 移动位置 | 按住鼠标左键拖动，位置自动记忆 |
| **贴边收起** | 拖到屏幕边缘松手 → 自动滑入收起，边缘留一个进度小条 |
| **从收起中唤出** | 鼠标移到边缘的进度小条上 → 自动弹出；移开后自动收回 |
| **切换配色** | 右键 → 配色主题 → 自动（跟随背景）/ 深色 / 浅色 |
| 打开菜单 | 鼠标右键点悬浮窗（收起状态下小条也可以右键） |
| 立即刷新 | 右键 → 立即刷新 |
| 修改设置 | 右键 → 设置… |
| 开机自启 | 右键 → 开机自启 → 设置 |
| 退出 | 右键 → 退出 |
| 重复打开 | 已在运行时会提示，不会出现两个浮窗 |

## 三、主窗口：额度详情面板

不贴边时，悬浮窗就是一个完整的额度面板，信息一目了然：

- **头部**：标题 + 更新时间（精确到秒）
- **每个供应商**：名称 + 套餐等级徽章（如 LITE / PRO），双供应商自动加分隔线
- **每个额度窗口**：大字百分比 + 进度条 + **重置倒计时和绝对时间**
  （如「35 小时 14 分后重置 · 9月6日（周日）10:08」）
- **智谱 MCP 联网工具**：月度用量、重置日期、分模型明细（search-prime / web-reader / zread）
- **火山窗口**：已用 / 总量具体数值（如「已用 1200 / 5.0w」）
- **页脚**：自动刷新间隔提示

数据自动按设置的间隔刷新；窗口停留期间每 30 秒自动更新倒计时文字。
觉得面板大小不合适：设置 → 显示与提醒 → 界面缩放。

## 四、贴边自动收起

把悬浮窗拖到屏幕任意一条边（左右上下都行）附近松手：

1. 悬浮窗**自动滑入屏幕边缘**收起，完全不挡内容
2. 边缘留一条**极窄的进度小条**：每个供应商一组微型进度条
   （左右贴边时是两根竖条：一根 5 小时、一根本周，像液体液位一样从底部涨起来；上下贴边时是两根横条）
3. 颜色规则和主界面一致：绿=正常、黄=偏高、红=临界 —— **不用扒开也能一眼看到用量**
4. 鼠标移到小条上 → 自动滑出**详情面板**（以小条中心为轴展开）；鼠标一移开 → 立刻收回
5. 从收起状态按住拖动 → 直接拽出来放到别处

不想用这个功能：右键 → 取消勾选「贴边自动收起」。

### 从收起唤出的面板

就是第三节那个详情面板。数据超过 2 分钟没刷新时展开会自动拉取最新额度。
把面板**拖离边缘**即恢复为自由窗口。

> 收起状态、贴哪条边都会记忆，重启程序自动恢复。

## 五、设置项说明（右键 → 设置…）

设置窗口为 Win11 风格卡片式界面（CustomTkinter 渲染；未安装该依赖时自动回退经典样式），
左侧分栏导航：**供应商密钥** / **显示与提醒**。

### 供应商密钥

| 设置 | 说明 |
|---|---|
| 启用 智谱 Coding Plan | 卡片右上角开关，不需要就关掉，卡片立即隐藏 |
| API Key | 智谱开放平台 → API Keys 页面获取 |
| 接口地址 | 默认 `open.bigmodel.cn`；国际版（z.ai）填 `api.z.ai` |
| 近 30 / 15 / 7 天用量 | 勾选要在详情面板显示的智谱历史 token 用量行 |
| 启用 火山引擎 Agent Plan | 同上，只用智谱就关掉 |
| AccessKey ID / SecretAccessKey | 火山引擎控制台 → 右上角头像 → **API 访问密钥**（AKLT 开头）。注意：**不是**方舟里的模型 API Key |
| 地域 | 一般 `cn-beijing` |

> 只用智谱一家？把火山的「启用」关掉即可，浮窗只显示智谱，更省地方。

### 显示与提醒

| 设置 | 说明 |
|---|---|
| 配色主题 | 自动 / 深色 / 浅色（分段选择）——自动模式会感应窗口背后的背景明暗切换深浅色 |
| 界面缩放 | 75%（紧凑）～130%（大），觉得浮窗太大/太小就调这里，保存后立即生效 |
| 窗口透明度 | 60% ～ 100%（步进器调节） |
| 贴边收起 | 开关"拖到边缘自动收起"功能 |
| 长条长度 | 贴边收起小条的长度（40～240px，步进 10 调节，默认 150），保存后立即生效 |
| 自动刷新间隔 | 1 ～ 120 分钟 |
| 黄色/红色阈值 | 用量超过黄档变黄、超过红档变红 |
| 系统通知 | 跨阈值 / 烧速预测 / 临近重置时弹 Windows 通知，每窗口期一次 |
| 开机自启 | 「设置自启 / 取消自启」按钮，操作后悬浮窗下方会弹气泡提示结果 |

### 颜色规则

- 绿色：正常（低于黄色阈值）
- 黄色：偏高（≥ 黄色阈值，默认 80%）
- 红色：临界（≥ 红色阈值，默认 95%）

## 六、显示内容

| 供应商 | 窗口 | 含义 |
|---|---|---|
| 智谱 Coding Plan | 5小时 | 当前 5 小时滚动窗口已用百分比 |
| | 本周 | 本周额度已用百分比 |
| 火山 Agent Plan | 5小时/本周/本月 | 各限额窗口已用百分比（套餐档位显示在标题旁） |

## 七、常见问题

| 现象 | 原因与解决 |
|---|---|
| 白色背景下看不清 | 配色主题设为「浅色」，或用「自动（跟随背景）」；透明度调太低也会冲淡对比，建议 80% 以上 |
| 提示「API Key 无效或已过期」 | Key 复制不完整或已失效，重新从智谱控制台复制 |
| 提示「InvalidAccessKey」 | 填的是方舟模型 Key；要用控制台头像 → API 访问密钥 里 AKLT 开头那对 |
| 提示「SignatureDoesNotMatch」 | SecretAccessKey 复制不完整，重新完整复制 |
| 提示「AK/SK 没有方舟查询权限」 | 这对 AK/SK 还没开通方舟权限：登录火山引擎控制台 → 访问控制 IAM → 该子用户 → 添加 `ArkFullAccess` 权限（或最少 ark:GetAFPUsage 只读权限） |
| AK 栏粘成了一整段（含 Secret Access Key 字样） | v2.3.2 起会自动拆分，无需处理；也可以手动把 AKLT 开头那段单独填进 AK 栏 |
| 双击没反应 | 看看是否已有悬浮窗在运行（单实例保护）；或查看本目录 `error.log` |
| 收起后找不到悬浮窗 | 看屏幕四条边上的窄进度条，鼠标移上去就会弹出；或重启程序 |
| Windows 弹防火墙提示 | 允许即可（需要联网查额度） |
| 公司网络一直更新失败 | 需要代理的网络暂不支持，可换家庭网络 |
| 浮窗跑到屏幕外 | 重启程序会自动复位到默认位置 |

## 八、版本更新与回退

各版本改动见同目录 [`版本日志.md`](版本日志.md)；每个发布版本的 EXE 存放在
[GitHub Releases](https://github.com/joeyxd19/llm-usage-widget/releases)。想回退到旧版：

1. 退出当前悬浮窗（右键 → 退出）
2. 从 Releases 页下载想要的历史版本 EXE，双击运行

各版共用同目录的 `config.json`，回退后新配置字段会被自动忽略，不影响使用。

## 九、目录结构

```
llm-usage-widget\
├── llm-usage-widget_vX.X.X.exe   ← 双击运行
├── config.json                   ← 首次保存设置后自动生成（密钥在这里）
├── history.jsonl                 ← 本地用量历史（烧速预测用，保留 14 天）
└── error.log                     ← 崩溃日志（出问题先看这里）
```

从源码打包 EXE（与 CI 一致的命令）：

```bash
pip install pyinstaller==6.22.3 customtkinter==6.0.0
pyinstaller --onefile --noconsole --clean --collect-all customtkinter \
  --name 额度悬浮窗 src/usage_widget.pyw
```

数据来源：智谱开放平台用量接口、火山方舟 GetAFPUsage 接口，仅在你本机调用。
